# Repository rules

Use ASD-STE100 Issue 9 for all new or changed human-readable text.
Apply this rule to skill files, templates, metadata, commit messages, pull requests, comments, and agent responses.
Read the [language rules](skills/new-repo/SKILL.md#use-asd-ste100) before you write.
Use the [technical terms](skills/new-repo/SKILL.md#technical-terms-for-this-skill) for skill work.

Keep skill instructions in `SKILL.md`.
Keep output templates in `assets/`.
Do not add a reference directory or reference files.
Do not add copies of the STE standard.
